# LLM NLP Journey

This repository documents my hands-on learning journey through Natural Language Processing (NLP) and Large Language Models (LLMs), covering both foundational techniques and modern transformer-based architectures.

---

## Overview

The repo includes implementations, experiments, and assignments focused on:

- Text preprocessing and tokenization
- Word embeddings (FastText, GloVe)
- Transformer architectures (BERT, IndicBERT, BART)
- Sequence-to-sequence modeling
- Model evaluation using CER and WER
- Optimization and normalization techniques

---

## Key Concepts Covered

### Embeddings

- Word2Vec
- FastText
- GloVe
- Understanding semantic similarity and vector spaces

### Transformer Models

- BERT (Bidirectional Encoder Representations from Transformers)
- IndicBERT (for multilingual/Indic languages)
- BART (encoder-decoder architecture)

### Model Internals

- Attention mechanisms
- Encoder-decoder architecture
- Training dynamics

### Normalization Techniques

- Layer Normalization
- RMSNorm
- pRMSNorm

### Positional Encoding

- Absolute positional encoding
- Relative positional encoding
- RoPE (Rotary Positional Encoding)

---

## Evaluation Metrics

- CER (Character Error Rate)
- WER (Word Error Rate)
- F1,accuracy,Precision,Recall
- BLEU, Bert score, chrF++

---

## Experiments

- Comparison of embedding techniques
- Comparison of normalization techniques (LayerNorm vs RMSNorm vs pRMSNorm)
- Impact of positional encoding methods
- Performance analysis across transformer variants
- Training and evaluation on real datasets
- One shot, Zero shot, Few Shot prompting techniques
- BPE, SentencePiece Tokenisers
